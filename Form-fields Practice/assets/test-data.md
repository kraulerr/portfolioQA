# Тестовые данные для формы регистрации OpenCart

## Типовые валидные данные

| Поле | Значение |
|------|----------|
| Имя | Ivan |
| Фамилия | Petrov |
| E-Mail | test@example.com |
| Телефон | +7 999 123 45 67 |
| Пароль | Password123 |
| Подтверждение пароля | Password123 |
| Подписка на новости | Отмечено (опционально) |
| Политика конфиденциальности | Отмечено |

## Данные для тестирования

### Имя / Фамилия
- Пустое значение
- 1 символ (A) — валидно
- 32 символа (максимальная длина) — валидно
- 33+ символа — ошибка
- 12345 (только цифры) — проверка
- !@#$% (только спецсимволы) — проверка
- Иван (кириллица) — валидно
- Ivan (латиница) — валидно

### E-Mail
- testexample.com (без @) — ошибка
- test@ (без домена) — ошибка
- test @example.com (с пробелом) — ошибка
- !test@example.com (спецсимвол в начале) — ошибка
- test@example.com — валидно
- TEST@EXAMPLE.COM (верхний регистр) — валидно
- test@mail.example.com (поддомен) — валидно
- test1@example.com — валидно, для валидной регистрации
- test@example.com (дубликат) — ошибка «E-Mail адрес уже зарегистрирован»

### Телефон
- 12 (2 символа) — ошибка
- 123 (3 символа, мин. длина) — валидно
- +7 999 123 45 67 (10–12 цифр) — валидно
- 12345678901234567890123456789012 (32 символа, макс. длина) — валидно
- 123456789012345678901234567890123 (33 символа) — ошибка
- ABCDEFGHIJ (только буквы) — проверка
- +7 (999) 123-45-67 (спецсимволы) — валидно

### Пароль
- 123 (3 символа) — ошибка
- Pass (4 символа, мин. длина) — валидно
- Password123 (11 символов) — валидно
- Password12345678901234567890 (20 символов, макс. длина) — валидно
- Password123456789012345678901 (21 символ) — ошибка
- Pass@word!123 (спецсимволы) — валидно

### Политика конфиденциальности
- Не отмечено — ошибка
- Отмечено — валидно
