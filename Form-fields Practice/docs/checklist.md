# Чек-лист для тестирования формы регистрации OpenCart

## Общие проверки

- [ ] Форма отображается корректно на разных разрешениях экрана (desktop, tablet, mobile)
- [ ] Все обязательные поля помечены звёздочкой (*) или иным индикатором
- [ ] Кнопка Continue активна и кликабельна
- [ ] Верстка не «плывёт» при изменении размера окна
- [ ] Все элементы формы читаемы и не накладываются друг на друга
- [ ] Есть ссылка «Login» для уже зарегистрированных пользователей
- [ ] Ссылка на Privacy Policy работает (открывает политику конфиденциальности)

## Поле Имя (обязательное)

- [ ] Пустое поле → ошибка «Имя должно быть от 1 до 32 символов!»
- [ ] Ввод имени из 1 буквы (A) → принимается
- [ ] Ввод имени из 32 букв (максимальная длина) → принимается
- [ ] Ввод имени из 33+ букв → ошибка «First Name must be between 1 and 32 characters!»
- [ ] Ввод имени с цифрами (Ivan123) → проверка (принимается или ошибка)
- [ ] Ввод имени со спецсимволами (Ivan@#) → проверка (принимается или ошибка)
- [ ] Ввод имени с пробелами (Ivan Petrov) → проверка (принимается или ошибка)
- [ ] Ввод кириллицы (Иван) → принимается
- [ ] Ввод латиницы (Ivan) → принимается
- [ ] Ввод эмодзи (😀) → проверка (принимается или ошибка)
- [ ] Пробелы в начале/конце ( Ivan ) → проверка (обрезаются ли пробелы)

## Поле Фамилия (обязательное)

- [ ] Пустое поле → ошибка «Фамилия должно быть от 1 до 32 символов!»
- [ ] Ввод фамилии из 1 буквы (A) → принимается
- [ ] Ввод фамилии из 32 букв → принимается
- [ ] Ввод фамилии из 33+ букв → ошибка
- [ ] Ввод кириллицы (Петров) → принимается
- [ ] Ввод латиницы (Petrov) → принимается

## Поле E-Mail (обязательное)

- [ ] Пустое поле → ошибка «E-Mail введен неправильно!»
- [ ] Email без @ (testexample.com) → ошибка «E-Mail введен неправильно!»
- [ ] Email без домена (test@) → ошибка
- [ ] Email с пробелами (test @example.com) → ошибка
- [ ] Email со спецсимволами в начале (!test@example.com) → ошибка
- [ ] Валидный email (test@example.com) → принимается
- [ ] Email в верхнем регистре (TEST@EXAMPLE.COM) → принимается
- [ ] Email с поддоменом (test@mail.example.com) → принимается
- [ ] Очень длинный email (255+ символов) → проверка на максимальную длину

## Поле Телефон (обязательное)

- [ ] Пустое поле → ошибка «Телефон должен быть от 3 до 32 цифр!»
- [ ] Телефон из 1–2 символов → ошибка «Телефон должен быть от 3 до 32 цифр!»
- [ ] Телефон из 3 символов (минимальная длина) → принимается
- [ ] Телефон из 10–11 цифр (+7 999 123 45 67) → принимается
- [ ] Телефон из 32 символов (максимальная длина) → принимается
- [ ] Телефон из 33+ символов → ошибка
- [ ] Телефон с буквами (123-ABC-4567) → проверка (принимается или ошибка)
- [ ] Телефон со спецсимволами (+7 (999) 123-45-67) → принимается
- [ ] Только буквы (ABCDEFGHIJ) → проверка (принимается или ошибка)

## Поле Пароль (обязательное)

- [ ] Пустое поле → ошибка «В пароле должно быть от 4 до 20 символов!»
- [ ] Пароль из 1–3 символов → ошибка «В пароле должно быть от 4 до 20 символов!»
- [ ] Пароль из 4 символов (нижняя граница) → принимается
- [ ] Пароль из 5–19 символов → принимается
- [ ] Пароль из 20 символов (верхняя граница) → принимается
- [ ] Пароль из 21+ символов → ошибка «В пароле должно быть от 4 до 20 символов!»
- [ ] Пароль только из букв (Password) → принимается
- [ ] Пароль с цифрами (Password123) → принимается
- [ ] Пароль со спецсимволами (Pass@word!123) → принимается
- [ ] Пароль отображается в виде звёздочек/точек → да

## Поле Подтверждение пароля (обязательное)

- [ ] Пустое поле → ошибка «Пароли не совпадают!»
- [ ] Пароли совпадают → принимается
- [ ] Пароли не совпадают → ошибка «Пароли не совпадают!»
- [ ] Разный регистр (Password vs password) → ошибка (чувствителен ли регистр)
- [ ] Пустое поле Password + заполненное Password Confirm → ошибка на оба поля

## Чекбокс Подписка на новости (необязательное)

- [ ] Чекбокс не отмечен → регистрация проходит успешно
- [ ] Чекбокс отмечен → регистрация проходит успешно, подписка активна
- [ ] Состояние чекбокса по умолчанию (отмечен/не отмечен) → соответствует настройкам

## Чекбокс Privacy Policy (обязательное)

- [ ] Чекбокс не отмечен → ошибка «Вы должны прочитать и согласится с Политика Безопасности!»
- [ ] Чекбокс отмечен → принимается
- [ ] Ссылка на «Privacy Policy» работает → открывается страница с политикой
- [ ] Текст ссылки кликабелен и выделен

## Кнопка Продолжить

- [ ] При нажатии на кнопку с пустыми обязательными полями → валидация всех полей
- [ ] При нажатии на кнопку с частично заполненными полями → валидация заполненных
- [ ] При нажатии на кнопку со всеми валидными данными → успешная регистрация
- [ ] После успешной регистрации → сообщение об успехе / редирект в личный кабинет
- [ ] Кнопка меняет состояние при наведении (hover) → да
- [ ] Кнопка меняет состояние при нажатии (active) → да

## Сообщения об ошибках

- [ ] Ошибки отображаются рядом с соответствующими полями или сверху формы
- [ ] Ошибки выделены цветом (красный)
- [ ] Текст ошибок понятный и конкретный
- [ ] Ошибки исчезают при исправлении поля (или после повторной валидации)
- [ ] Ошибки не перекрывают другие элементы формы

## Дополнительные проверки

- [ ] Повторная регистрация с тем же email → ошибка « Данный E-Mail уже зарегистрирован!»
- [ ] Ввод данных с копированием/вставкой (Ctrl+C, Ctrl+V) → работает корректно
- [ ] Автозаполнение браузером → поля заполняются корректно
- [ ] Вкладка и навигация с клавиатуры (Tab, Enter) → работает корректно
- [ ] Проверка в разных браузерах (Chrome, Firefox, Safari) → форма работает одинаково
- [ ] Проверка на мобильном устройстве (или в режиме эмуляции) → форма адаптирована
