# Тест-кейсы для формы регистрации OpenCart

## TC-REG-01: Регистрация с валидными данными

**Предусловия:** Пользователь на странице регистрации, email ещё не зарегистрирован

**Шаги:**
1. Ввести Имя: Ivan
2. Ввести Фамилия: Petrov
3. Ввести E-Mail: test@example.com
4. Ввести Телефон: +7 999 123 45 67
5. Ввести Пароль: Password123
6. Ввести Подтверждение пароля: Password123
7. Отметить Подписка на новости (опционально)
8. Отметить Политика конфиденциальности
9. Нажать кнопку Продолжить

**Ожидаемый результат:** Сообщение об успешной регистрации, редирект в личный кабинет или на главную страницу

**Техника:** Эквивалентное разбиение (валидный класс)

**Приоритет:** High

---
