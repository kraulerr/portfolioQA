# BUG-01: Регистрация с паролем длиной более 20 символов

## Общая информация

- **ID:** BUG-01
- **Заголовок:** Форма регистрации принимает пароль длиной 21 символ и создаёт аккаунт
- **Компонент:** Форма регистрации OpenCart
- **Серьёзность:** Low
- **Приоритет:** Low
- **Статус:** New
- **Дата обнаружения:** 10.09.2026
- **Тест-кейс:** TC-REG-11
- **URL:** https://demo.opencart-cms.ru/create-account

## Окружение

### Операционная система

- **Система:** Windows 11 Домашняя
- **Версия:** 25H2
- **Сборка ОС:** 26200.9445
- **Функциональность:** Пакет интерфейса компонентов Windows 1000.26100.360.0
- **Разрядность:** 64-bit

### Браузер

- **Браузер:** Opera GX
- **Канал обновлений:** Early Access
- **Core:** 135.0.5973.94
- **Версия Chromium:** 151.0.7922.170
- **Система браузера:** Windows 11 64-bit

### Подключение

- **Тип подключения:** Wi-Fi

## Краткое описание

Форма регистрации принимает пароль длиной 21 символ, хотя согласно проверяемому правилу максимальная допустимая длина пароля составляет 20 символов.

После отправки формы регистрация завершается успешно, и аккаунт создаётся.

## Предусловия

1. Пользователь не авторизован на сайте.
2. Используется новый, ранее не зарегистрированный email.
3. Открыта страница регистрации:
   https://demo.opencart-cms.ru/create-account

## Тестовые данные

| Поле | Значение |
|------|----------|
| Имя | Ivan |
| Фамилия | Petrov |
| E-Mail | test1234@example.com |
| Телефон | +7 999 123 45 67 |
| Пароль | Password1234567890123 |
| Подтверждение пароля | Password1234567890123 |
| Политика конфиденциальности | Отмечена |

Длина значения в полях «Пароль» и «Подтверждение пароля» — 21 символ.

## Шаги воспроизведения

1. Открыть страницу регистрации:
   https://demo.opencart-cms.ru/create-account
2. Ввести в поле «Имя» значение `Ivan`.
3. Ввести в поле «Фамилия» значение `Petrov`.
4. Ввести уникальный email.
5. Ввести в поле «Телефон» значение `+7 999 123 45 67`.
6. Ввести в поле «Пароль» значение длиной 21 символ:
   `Password1234567890123`
7. Ввести в поле «Подтверждение пароля» то же значение.
8. Отметить «Политика конфиденциальности».
9. Нажать кнопку «Продолжить».

## Ожидаемый результат

Система должна отклонить пароль длиной более 20 символов.

Должно появиться сообщение:

> «Пароль должен быть от 4 до 20 символов!»

Форма не должна отправляться, и новый аккаунт не должен создаваться.

## Фактический результат

Форма приняла пароль длиной более 20 символов.

Сообщение об ошибке не отобразилось. Регистрация завершилась успешно, после чего аккаунт был создан.

## Воспроизводимость

- **Воспроизводимость:** 1 из 1 попытки
- **Результат:** Passed as defect / баг воспроизводится

После дополнительной проверки повторное воспроизведение желательно выполнить с новым email, чтобы исключить влияние уже существующей учётной записи.

## Влияние

Пользователь может создать аккаунт с паролем, который не соответствует установленному ограничению длины.

Это может привести к:

- Несоответствию между правилами интерфейса и фактической логикой регистрации.
- Разным правилам в формах регистрации, входа и восстановления пароля.
- Ошибкам при последующей авторизации или смене пароля.
- Проблемам при интеграции с другими компонентами системы, если они ожидают пароль длиной не более 20 символов.
