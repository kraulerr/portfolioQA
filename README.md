# QA Manual Testing Portfolio

Добро пожаловать в моё портфолио начинающего специалиста по ручному тестированию программного обеспечения.

В репозитории собраны два учебных проекта, демонстрирующих практические навыки тестирования REST API и веб-форм.

## Проекты

### 1. Тестирование API в Postman

Папка: ReqRes API Practice.

В проекте выполнено тестирование публичного REST API с помощью Postman.

Проект демонстрирует навыки:

- работы с HTTP-методами GET, POST, PUT, PATCH и DELETE;
- проверки статус-кодов HTTP;
- анализа тела ответа в формате JSON;
- проверки обязательных полей и типов данных;
- тестирования позитивных и негативных сценариев;
- проверки обработки ошибок;
- работы с коллекциями и Collection Runner;
- документирования результатов тестирования.

В папке находятся:

- коллекция Postman;
- тест-кейсы;
- примеры API-запросов;
- скриншоты запросов и ответов;
- описание проекта и инструкция по запуску.

### 2. Тестирование формы регистрации

Папка: Form-fields Practice.

В проекте выполнено тестирование формы регистрации демонстрационного интернет-магазина от OpenCart.

В рамках проекта проверялись:

- обязательные поля формы;
- имя и фамилия пользователя;
- адрес электронной почты;
- номер телефона;
- пароль и подтверждение пароля;
- согласие с политикой конфиденциальности;
- подписка на новости;
- валидация пользовательских данных;
- корректность сообщений об ошибках;
- успешное создание аккаунта;
- повторная регистрация с уже используемым email.

В проекте применялись следующие техники тест-дизайна:

- эквивалентное разбиение;
- анализ граничных значений;
- таблицы решений;
- сценарное тестирование;
- комбинаторное тестирование.

В папке находятся:

- чек-лист;
- таблица тест-кейсов;
- тестовые данные;
- баг-репорт найденного дефекта;
- скриншоты результатов тестирования;
- описание проекта и инструкция по воспроизведению проверок.
